# Автоматизированный SecOps-пайплайн в Docker

Проект демонстрирует навыки контейнеризации, автоматизированного поиска уязвимостей (DAST) и обеспечения безопасности веб-приложений. Включает в себя уязвимый микросервис и изолированный контейнер-сканер.

## 🏗️ Архитектура проекта

Проект разворачивается в изолированной Docker-сети (`secure_net`) и состоит из двух компонентов:
1. **web-app** (Порт `5000`): Веб-приложение на Flask, содержащее уязвимость SQL-инъекции (SQLi) в форме авторизации.
2. **security-scanner**: Контейнер-аудитор, который автоматически тестирует веб-приложение на наличие уязвимостей при запуске инфраструктуры.

## 🚀 Быстрый запуск

Для запуска всего окружения необходим установленный Docker и Docker Compose.

```bash
# Клонировать репозиторий
git clone https://github.com
cd docker-security-scanner

# Запустить проект
docker-compose up --build
```

## 🔍 Демонстрация работы (Логи сканера)

При успешном запуске сканер обнаружит уязвимость и выведет в консоль:
```text
[+] Запуск сканирования безопасности на: http://web-app:5000/login
[!] ВНИМАНИЕ: Обнаружена критическая уязвимость SQL-injection!
[!] Использован payload: admin' OR '1'='1
```
